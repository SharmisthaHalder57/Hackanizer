# 🚀 Hackanizer

### Smart AI-Powered Hackathon Management Platform

Hackanizer is a comprehensive hackathon management platform designed to simplify and automate the entire hackathon lifecycle. From participant onboarding and mentor allocation to room tracking, food coupon management, emergency support, and event analytics, Hackanizer provides a centralized ecosystem for organizers, participants, mentors, judges, and volunteers.

---

## 🌟 Features

### 🔐 Role-Based Access Control (RBAC)

* Organizer
* Participant
* Mentor
* Judge
* Volunteer

Each role has its own dashboard and permissions, ensuring secure and efficient event management.

---

### 🆔 Code-Based Login System

Organizers can create a hackathon and automatically generate unique login codes for every member.

#### Example

| Role         | Code Format |
| ------------ | ----------- |
| Participants | P001 - P200 |
| Mentors      | M001 - M010 |
| Judges       | J001 - J010 |
| Volunteers   | V001 - V020 |

Invitation links containing unique access codes can be shared through:

* Email
* WhatsApp

This creates a dedicated event workspace ("Hack Room") for all stakeholders.

---

### 🚪 Smart Room Entry & Exit Tracking

Track participant movement across rooms.

---

### 🍽️ QR-Based Food Coupon System

Digital food coupons for:

* Breakfast
* Lunch
* Dinner

#### Workflow

1. User clicks **Claim Coupon**
2. QR Code appears instantly
3. QR is scanned at the food counter
4. Coupon status changes to **Claimed**
5. Organizer dashboard updates in real time

Prevents duplicate food claims and reduces manual verification.
